Jikan 時間 — Política de Privacidad

Última actualización: 9 de octubre de 2026

Política de privacidad Términos del servicio Volver a la aplicación

1. Qué es Jikan

Jikan es un planificador de horarios con visualización en rueda de 24 horas. Tus horarios, recordatorios y ajustes son tuyos: la aplicación es una herramienta de gestión personal, no un servicio de publicidad ni de analítica.

2. Qué datos se tratan y dónde se guardan

  • Sin cuenta (modo invitado): las actividades se guardan en una base de datos local del navegador (IndexedDB) en este dispositivo. No se envían a ningún servidor.
  • Con cuenta: las actividades se guardan en una base de datos PostgreSQL (Supabase) asociada a tu usuario, para poder acceder a ellas desde otros dispositivos.
  • Ajustes locales: recordatorios, disposición de paneles, tema, idioma y contadores del temporizador viven en el almacenamiento local del navegador (localStorage), ligados a tu usuario.
  • Cifrado: si activas el cifrado local, tu horario en el dispositivo se cifra con AES-GCM 256 antes de guardarse. La frase nunca se transmite ni se guarda: solo existe en memoria mientras la aplicación está abierta. Si la olvidas, no se puede recuperar.

Jikan no vende, alquila ni comparte tus datos con terceros con fines comerciales.

3. Copias de seguridad en Google Drive (opcional)

Si eliges usar la función «Copia en la nube», Jikan conecta con tu propia cuenta de Google para guardar copias de seguridad en tu Google Drive. Sobre esta integración:

  • La aplicación solicita únicamente el permiso drive.file: solo puede ver y gestionar los archivos de copia que ella misma crea. No accede al resto de tus archivos de Drive.
  • El token de acceso de Google se conserva solo en memoria mientras dura la sesión del navegador (se borra al recargar). No se almacena ningún token de renovación.
  • Las copias subidas se guardan como archivos JSON en tu Drive, en tu propio espacio de almacenamiento y sujetos a la política de privacidad de Google. Tú puedes eliminarlos cuando quieras desde la aplicación o desde Drive.
  • Si tienes el cifrado local activo, el contenido de la copia se cifra en tu dispositivo antes de subirse, de modo que Google no recibe el horario en claro.

4. Uso de información de las API de Google

El uso que Jikan hace de la información recibida a través de las API de Google y su transferencia a cualquier otra aplicación se ajustan a la política de datos de usuario de los Servicios de API de Google (Google API Services User Data Policy), incluidos los requisitos de Limited Use. Los datos obtenidos de Google se usan exclusivamente para crear y restaurar tus copias de seguridad en Drive; no se usan para entrenar modelos, ni se transfieren a terceros, ni se muestran en publicidad.

5. Tus derechos

  • Acceso y portabilidad: en Configuración → Datos puedes exportar todos tus datos en un archivo JSON (formato GDPR).
  • Supresión: puedes borrar actividades individualmente, restaurar ajustes o —con cifrado activo— usar el borrado de emergencia. Con cuenta, al cerrar sesión en otro dispositivo tus datos permanecen en tu cuenta; para eliminarlos definitivamente escríbenos.
  • Copias en la nube: se eliminan desde la propia aplicación (Configuración → Datos → Copia en la nube) o directamente desde tu Google Drive.

6. Contacto

Para cualquier cuestión sobre privacidad o para solicitar la eliminación de datos de una cuenta, abre una incidencia en el repositorio público del proyecto (github.com/Harold-ESC/Jikan-Maru).

7. Cambios

Cualquier cambio en esta política se publicará en esta misma página con una nueva fecha de actualización. Si un cambio fuera sustancial y afectase al tratamiento de datos ya guardados, se avisará dentro de la aplicación.
